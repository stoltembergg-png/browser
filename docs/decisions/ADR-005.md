# ADR-005 — Runtime lifecycle and quota manifest

- **Status:** proposed (accepted as gate for PR-020/023/025)
- **Date:** 2026-08-13
- **Owners:** repository maintainers
- **Related PRs:** PR-020, PR-023, PR-025

## Contexto

PR-020 introduce o browser core actor/lifecycle. O card exige "ADR-005/runtime manifest accepted" como gate. Sem um ADR e um manifesto de quota de runtime, o core não pode definir timeouts, backpressure e orderm de shutdown de forma determinística.

## Decisão

### Runtime lifecycle

O core actor transitionsa pelos estados definidos em `engine-api::contract::LifecycleState`:

```
Created → Starting → Ready → Navigating → Closing → Exited
                                       ↘ Failed → Restarting → Ready
                                       ↘ Crashed → Exited
```

Qualquer transição não listada falha fechado. Estados terminal (`Exited`) rejeitam commands.

### Quota manifest

O runtime manifest define:

| Parâmetro | Valor | Descrição |
|---|---|---|
| `command_timeout_ms` | 30000 | Timeout para um command individual |
| `queue_capacity` | 256 | Capacidade max da command queue (bounded) |
| `shutdown_drain_timeout_ms` | 5000 | Timeout para drain event loop no shutdown |
| `restart_max_attempts` | 3 | Max tentativas de restart após crash |
| `restart_backoff_ms` | 1000 | Backoff entre tentativas de restart |
| `input_coalesce` | true | Input/resize events podem ser coalescidos |
| `reliable_commands` | ["navigate", "reload", "shutdown"] | Commands que não podem ser descartados |

### Cancellation

- `Stop` cancela navigation atual: `NavigationCancelled` event.
- `Shutdown` cancela todos pending commands: `CommandCancelled` per command.
- Após `Exited`, todos pending commands retornam `CommandCancelled`.

### Shutdown ordera

1. Drop todos webview handles.
2. Drain `spin_event_loop` até retornar `false` ou timeout.
3. Drop render context.
4. Emit `EngineExited`.

### Backpressure

- Queue saturada → `QueueSaturated` event + diagnostics.
- Reliable commands nunca descartados silenciosamente.
- Input/resize podem coalescer (last-value-wins).

## Limites

- O manifest é proposto; ratificação formal é gate para PR-020/021/025/026.
- Os valores são defaults conservadores; ajuste requer ADR update.

## Consequências

- Timeouts são erros observáveis, não aborto inseguro.
- Backpressure é explícito, não silencioso.
- Shutdown é ordenado e determinístico.
- Restart é limitado e com backoff.
